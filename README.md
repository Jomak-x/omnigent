# Pre-chat workspace panel demo

Anonymous demonstration media for omnigent-ai/omnigent issue #7104.

The main video uses an Aurora sample workspace and real file/diff, shell, host/session lifecycle and a separate public GitHub PR. Only the short agent reply is a deterministic fixture. The native Electron supplement shows its initially blank Browser and panel resizing. No personal account details or private workspace paths are included.

Captured from the reviewed d1a9038 build. Later changes add error feedback and integrate upstream changes; final validation is recorded in the feature PR.

This media branch is separate from the product implementation.
